# Expense Splitter

A simple Java Swing desktop application that calculates how much each person should pay when an expense is shared among multiple people. The application provides a clean graphical interface with input validation and reset functionality.

## Features

* Enter total expense amount
* Enter number of people
* Calculates the share per person
* Validates empty and invalid inputs
* Prevents division by zero
* Reset button to clear all fields
* Simple Java Swing GUI

## Technologies Used

* Java
* Java Swing
* AWT
* Event Handling
* Exception Handling

## How It Works

The user enters the total expense and number of people. When **CALCULATE** is clicked, the program divides the total expense by the number of people and displays the amount each person should pay. Invalid inputs are handled with appropriate messages.
